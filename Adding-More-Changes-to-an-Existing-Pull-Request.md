# Adding More Changes to an Existing Pull Request

You can keep adding updates to the same pull request.  
You do not need to create a new pull request each time you want to make more changes.

## How to update the same pull request

1. Open the existing pull request.  
   ![Open the pull request and find the branch name](imagine_images/tocua.jpg)

2. Note the branch name under the title (the one it says “from”).

3. Go to the repository’s **Code** tab.  
   ![Switch to the branch](imagine_images/zu95d.jpg)

4. Use the branch dropdown (top left) and switch to that same branch.

5. Make your changes:
   - Edit a file by clicking the pencil icon, or
   - Upload a file with **Add file → Upload files**.  
     ![Edit a file with the pencil icon](imagine_images/nu89M.jpg)

6. Click **Commit changes…**.

7. Write a short commit message.

8. Make sure you commit **directly to the existing branch** (do not create a new branch).  
   ![Commit directly to the existing branch](imagine_images/H7Xga.jpg)

9. Return to the pull request — your new changes will already be there.

You can repeat these steps as many times as needed. Every update stays in the same pull request.

## Tips

- Always check that you’re on the correct branch before editing.
- Keep commit messages short and clear (example: “Update screenshots in Chapter 1”).
- If you don’t see the pencil icon or can’t commit, ask a teammate for access.
