# How to Add More Changes to the Same Pull Request
*A simple guide for non-technical users — no coding needed*

A Pull Request stays open and keeps collecting changes as long as you update the **same branch**.  
You do **not** need to make a new Pull Request each time.

---

## Step 1: Open the existing Pull Request

Go to the Pull Request. Near the top you’ll see the branch name (the one it says “from”).

**That’s the branch you’ll keep updating.**

---

## Step 2: Go to that branch

Click the branch name, or go to the repository and switch to that same branch using the branch dropdown.

---

## Step 3: Edit the file

1. Find the file you want to change.
2. Click the **pencil icon** (it looks like a pen) in the top-right of the file.
3. Make your changes in the simple editor that opens.

---

## Step 4: Save your changes to the same branch

1. Click the green **Commit changes…** button.
2. Write a short note about what you changed  
   *(example: “Updated the welcome text”)*.
3. Make sure it says it will commit **directly to the existing branch**  
   (the same one from the Pull Request).  
   **Do not** choose “Create a new branch.”
4. Click **Commit changes**.

---

## Step 5: Done — repeat whenever you need

Go back to the Pull Request. Your new changes will already be there.

You can do this as many times as you want. Every update goes into the **same** Pull Request.

---

### Quick tips

- Always check that you’re updating the branch shown in the Pull Request.
- Keep your notes short and clear.
- If you don’t see the pencil icon, ask a teammate for access.
